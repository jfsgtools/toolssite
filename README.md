Welcome to the **JFSG Tools** GitHub repository! This project provides a collection of tools designed to simplify the tasks of students from the [**Jacobus Fruytier scholengemeenschap (JFSG)**](https://jfsg.nl). These tools aim to streamline event planning, resource management, communication, and more.

## Overview

This repository contains the source code for the **JFSG Tools** platform, offering a variety of utilities to assist JFSG students with their daily tasks. The goal is to provide an open-source, easy-to-use, and collaborative space for the students.

---

## Features

- [x] **URL shortening**: Fast access to longer sites.
- [x] **Timeschedule tools**: Downloadable tools to enlarge your visual experience.
- [ ] **Find schedules of other students**: Still in progress.
